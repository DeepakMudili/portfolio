# Deepak Mudili — Python GenAI Portfolio

A modern React + Vite portfolio for Python GenAI, FastAPI, RAG, LangChain, semantic search, and AI backend projects.

## Live Deployment
Deploy this portfolio using GitHub Pages.

## Tech Stack
- React
- Vite
- CSS
- Framer Motion
- Lucide React
- GitHub Pages

## Local Setup
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to GitHub Pages
```bash
npm run deploy
```

## Important
Update `homepage` in `package.json` if your GitHub repo name changes.
